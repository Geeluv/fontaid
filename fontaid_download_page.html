How it works

01

Add your ZIP file

Drop in the ZIP exactly as it downloaded. Fontaid searches every folder inside it for you.

02

Choose the format

Pick OpenType (.otf), TrueType (.ttf), or both. Fontaid filters out everything else automatically.

03

Install

One click installs the fonts to your Windows account and refreshes the font cache. No restart needed.

Trust & safety

Verify your download

Check the file hasn't been tampered with

Compare the hash below with the one shown after you download fontaid.exe. If they match, the file is exactly what we published.

Get-FileHash "$env:USERPROFILE\Downloads\fontaid.exe" -Algorithm SHA256

Run that command in PowerShell, then compare the Hash value it prints against the SHA-256 shown above. Windows SmartScreen may still show a caution prompt for new, unsigned applications. That's expected for a small independent tool like this one; choose "More info" → "Run anyway" if you've verified the hash. You're welcome to scan the file yourself on VirusTotal first.
